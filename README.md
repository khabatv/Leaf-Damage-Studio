# Leaf-Damage-Studio
Leaf Damage Studio is an interactive, browser-based single-page web application designed for high-throughput leaf segmentation, damage assessment, morphometric profiling, and multi-treatment comparative analysis.

Features
Segmentation & Interactive Editing: Automatic background thresholding, Otsu/watershed segmentation, plus brush, split, and include/exclude manual adjustment tools.

Leaf Reconstruction & Damage Quantification: Reconstruction of missing leaf regions (Catmull-Rom splines, bilateral mirroring, convex hull, ellipse fitting) to calculate hole damage, margin damage, and total missing area.

In-Depth Morphometrics & Feature Extraction: Extraction of over 60 shape, size, boundary, moment-based (Hu, Zernike), texture (GLCM), color, and spatial metrics per leaf.

Multi-Scan & Treatment Comparisons: Grouping, multi-scan storage, statistical testing (ANOVA, Tukey HSD, Kruskal-Wallis), and plant schematic / mirror / radar visualizations.

AI Integration: Multi-model AI batch segmentation workflows (MobileSAM, LeafNet color/edge/HSV/hybrid engines).

Usage
Open Leaf_Damage_Studio_v9.18.html in any modern web browser (Google Chrome, Mozilla Firefox, or Microsoft Edge). No server installation or external dependencies are required.
